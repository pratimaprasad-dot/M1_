# Data

No external dataset is used: all data are generated by Monte-Carlo simulation of the system model
(random Rayleigh channels, Gamma-textured compound-Gaussian clutter, Gaussian CSI errors).
The files here are the saved final campaign used in the report (100 paired channels per point).
They can be regenerated with `Code/src/<experiment>/run_experiment.py --runs=100`.

## Simulation setting (Hu et al. MIMO setup + our clutter and CSI model)
| Parameter | Value |
|---|---|
| DBS antennas | Nt = Nr = 8 |
| Secondary transmitter-receiver pairs | M = 4 |
| Radar targets | K = 4 at -45, 0, 45, 90 degrees |
| Link distance / path-loss exponent | 100 m / 4 |
| ST power Pc, DBS power Pmax | 20 dBm, 20 dBm |
| Noise power | -80 dBm |
| Radar power / target echo | 20 dBm / -90 dB |
| Clutter | Gamma texture, shape k = 0.7, CNR 0 dB |
| CSI error | variance ratio eps = 0.01 on all channels |
| Detection | P_FA = 1e-3, required P_D = beta = 0.9, L = 1 |
| Evaluation | 32 texture nodes x 16384 Sobol points per target |

## Files
| File | Contents |
|---|---|
| `sweep_beta.csv`, `sweep_eps.csv`, `sweep_shape.csv`, `sweep_Pc.csv`, `sweep_Pmax.csv`, `sweep_Nr.csv`, `sweep_Nt.csv` | One row per (x-value, channel, scheme) |
| `validation.json` | Model vs brute-force checks (experiment 11) |
| `convergence.json` | Design-model sum rate per iteration, 30 channels x 3 beta (experiment 10) |
| `quadrature_margin.json` | Design-time P_D error vs dense reference, 60 channels (experiment 12) |
| `run_info.json` | Software versions, seeds and settings of the campaign |

## Columns of `sweep_*.csv`
| Column | Meaning |
|---|---|
| `sweep`, `x` | Swept parameter and its value |
| `run` | Channel index (seed = 1000 + run, same channel for every scheme) |
| `scheme` | Design (Proposed, Hu Alg.1 ..., Perfect CSI ...) |
| `status` | Solver outcome (`ok`, `infeasible`, ...) |
| `SAR` | Sum achievable rate of the secondary users (bps/Hz) |
| `PD_min`, `PD_mean` | Worst-target and average detection probability under the TRUE law |
| `protected` | True if every target has P_D >= beta (within 1e-3) |
| `SINR_min_dB` | Worst-target sensing SINR |
| `relay_W`, `p_sum_W` | Relay transmit power and total secondary power (W) |
| `iters`, `seconds` | Outer iterations and run time of the design |
